## Two portfolios, not one

- A **group** GitHub Pages site.
- An **individual** portfolio for each student.
- One doesn't replace the other (confirmed per VoltPop, 2026-08-28).

---

## Group site, step by step

1. In your team repo, add a minimal `index.html` (repo root or a
   `docs/` folder).
2. GitHub → repo **Settings → Pages** → Source: *Deploy from a branch*
   → `main` → `/ (root)` or `/docs` → Save.
3. Confirm the published `github.io` URL loads (can take a couple
   minutes the first time).
