## Pick a license

- Plain-language version: **this file just says what other people are
  allowed to do with your code.**
- Default for this course: **MIT** — permissive, one short paragraph,
  the most common choice for a student/portfolio project.
- Add it, move on. This isn't a license-comparison exercise.

## Contribution norms, briefly

- Small commits, a branch per change — not everything dumped straight
  onto the main line.
- Worth naming directly: **this is the same model the program's own
  team uses to keep its own notes in sync** — you're not learning a
  toy version of something, you're doing the real thing the adults
  running this program do.
