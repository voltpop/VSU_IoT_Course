# Press Kit Assets

One landing-pad folder per company, each self-contained:

- `voltpop/`
- `builder-tech/`
- `explay/`
- `nicholson-llc/` (Dr. Shawn M. Nicholson LLC)

Each folder holds that company's four press-kit pieces:

- `logo.*` — company logo (any image format — png/jpg/svg).
- `headshot.*` — headshot of that company's named instructor/principal.
- `about-me.md` — a personal blurb from that person.
- `about-company.md` — a blurb about the company itself.

`about-me.md`/`about-company.md` start as drafts (adapted from this
KB's existing text) — each company should edit and commit their own
final version, and drop `logo.*`/`headshot.*` in alongside them.

VSU itself isn't a company with a landing pad here — its logo/blurb
needs are simpler (institutional, no personal headshot) and tracked
directly in `Press-Kit-Content.md`.
